Font Choices

I chose Arial for body text because it is simple and easy to read.

I chose Georgia for headings to make them stand out from the body text.

Both fonts are commonly available system fonts, so I do not need to download them from another website.

If Arial is unavailable, the browser will try Helvetica and then a generic sans-serif font.

If Georgia is unavailable, the browser will try Times New Roman and then a generic serif font.
